# Chick Talk(チックトーク)

架空のSNS画面(タイムライン)を作って、画像として保存できるツールです。
キャラを登録して、投稿・返信・引用・画像・プロフィール画面を並べ、PNG / JPG で保存できます。

- 1つの HTML ファイル(`index.html`)だけで動きます
- 入力した文章や画像は、お使いのブラウザの中だけで処理されます(外部には送られません)
- テーマ: Chick Talk(オリジナル)/ X風 / Bluesky風 / Threads風、ダーク・ライト切り替え

## 使い方

`index.html` をブラウザで開くだけです。

GitHub Pages で公開する場合は、リポジトリの **Settings → Pages** で、公開するブランチ(`main`)と場所(`/ (root)`)を選んで保存してください。しばらくすると、公開用のアドレスが表示されます。
